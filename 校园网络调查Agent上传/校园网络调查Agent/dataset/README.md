# 模拟数据说明

cases.json为手工构造的8组公开开发案例；不含真实设备、真实学校地址或实测数据。每组包含链路基线/异常指标、去程路径、接入观测和示意拓扑。容量单位Mbps，RTT单位ms，利用率/丢包率为百分数，队列为包，速率参数为包/秒，端口错误为5分钟计数。

链路探测RTT与接入有线/无线对照是不同测点的记录，不能相加；若要对整个路径的时延做严格归因，需要补充端到端同步测量及每项测量的目标定义。初版的队列估计只作方向和量级辅助检查，不能证明全部RTT增量来源。

queue_model.assumptions_met是模拟器指定的模型适用条件，不是Agent测出来的事实。工具依据该条件决定是否返回M/M/1稳态结果；真实部署需要先检验流量过程和服务过程。

rubrics.json只供evaluate.py使用，Agent和网页案例接口不会读取该文件。预期类别来自手工构造场景，不能认为所有案例都存在唯一真实答案。尤其C03同时含速率下降与排队拥塞，当前类别匹配指标要求rate_drop，这会把只标congestion但已识别速率变化的回答计为不匹配；正式评测应预先写明根因、机制及多因并存的评分口径，不能看到结果后修改本轮答案来提高分数。

开发案例用于检查和改进程序；正式报告另建未用于调试的测试案例，并固定评分标准、重复次数和模型条件。
